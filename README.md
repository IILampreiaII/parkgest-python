Formandos: Eduardo Moreira, João Lampreia, Geraldine Guevara

Projeto: Sistema de Gestão de Parques de Estacionamento

Descrição do Módulo: Entrada no Parque

O projeto ParkGest foca-se no desenvolvimento de um sistema inteligente para a gestão de parques de estacionamento.
